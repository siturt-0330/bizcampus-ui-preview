# ビズキャンプラス UIプレビュー

既存サイトの内容を活かした、確認用の静的UIプロトタイプです。
本番のWordPressとは別に公開してください。

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作成。名前は bizcampus-ui-preview、公開範囲は Public。
2. このZIPを解凍。index.html・style.css・app.js・data.json・assetsフォルダーをリポジトリ直下にアップロード。ZIPのままアップロードしないでください。
3. リポジトリの Settings → Pages を開く。
4. Build and deployment の Source で Deploy from a branch を選ぶ。
5. Branch は main、フォルダーは / (root) を選んで Save。
6. 公開完了後、Settings → Pagesに表示されるURLを共有。

重要: index.html がリポジトリ直下にあることを確認してください。
記事やメンバーをクリックすると、元のビズキャンプラスのページへ移動します。
表示データは試作時点のスナップショットで、WordPressへの投稿追加は自動反映されません。
